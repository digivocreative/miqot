# Calon Haji 2027 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu Dashboard "Calon Haji 2027": daftar bersama ±1.416 calon jamaah Haji Khusus dari PDF kantor, bisa dicari/difilter semua agent, diisi lewat skrip impor.

**Architecture:** Parser murni (`lib/calon-haji-parser.js`) mengubah teks `pdf-parse` jadi baris; skrip CLI memvalidasi lalu menulis lewat `lib/calon-haji-store.js` ke tiga tabel (impor, baris, penunjuk impor aktif — penggantian atomik = satu UPDATE penunjuk). `GET /api/calon-haji` mengembalikan seluruh baris impor aktif; halaman React memfilter di klien dengan helper murni `src/lib/calonHaji.js`.

**Tech Stack:** Node 22 ESM, Express (`server.js`), Supabase JS (service key), `pdf-parse` v2 (`PDFParse`), React + Tailwind + framer-motion, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-22-calon-haji-2027-design.md` · Mockup: Pencil `Haji2027.pen` frame 01/02/03.

## Global Constraints

- Commit langsung di `main`; `git add` per berkas; jangan push.
- Repo publik: **jangan commit data jamaah asli** (nama/NIK/porsi dari PDF). Fixture = sintetis.
- DB lokal = produksi. Skrip impor default `--dry-run`; tulis hanya dengan `--write`. Migrasi dijalankan **user** (`docker exec -i sb-db psql -U postgres -d postgres < migrations/<file>.sql`).
- Label UI persis: menu & header **"Calon Haji 2027"**; subjudul kartu **"Cek status berhak lunas & cadangan"**; tab **"Semua" / "Berhak Lunas" / "Cadangan"**; status baris **"Berhak Lunas"** (emerald) / **"Cadangan"** (amber); lencana **"✓ LUNAS"**; placeholder cari **"Cari nama, no. porsi, atau NIK…"**; pil JKN **"Semua" / "Aktif" / "Belum Aktif" / "Tidak Ada"**; tombol sheet **"Reset"** + **"Tampilkan {N} jamaah"**.
- Tidak ada judul besar, keterangan, tanggal data, atau baris "N jamaah" di halaman.
- Kab/kota di baris tabel: buang awalan `KOTA `, `KAB.` tetap; usia di baris yang sama: `"Jakarta Timur · 47 th"`. Detail memakai nama lengkap.
- Pemetaan JKN: `AKTIF`→Aktif; `TERDAFTAR, BELUM AKTIF`→Belum Aktif; `null` (dari `-`) dan `BELUM TERDAFTAR`→Tidak Ada.
- Berhak Lunas ⇔ `status_cadangan === 'NON CADANGAN'`. Lunas ⇔ `status_jemaah === 'LUNAS'` (tidak memengaruhi tab/hitungan).
- Musim = `2027`. URL `/dashboard/calon-haji-2027`. API `/api/calon-haji`.
- Dark mode wajib; `max-w-lg`; ikon `src/components/bio/KaabaIcon.tsx`.
- Verifikasi Claude: tes unit terkait (`node --test tests/<file>`), `node --check server.js`, `npm run build`. User menjalankan e2e/suite penuh.

## Review Focus

1. Supabase memotong SELECT di 1.000 baris diam-diam → `loadCalonHaji` wajib paging `range()` sampai habis (tes Task 2: 2.300 baris palsu kembali utuh).
2. Impor gagal di tengah (insert batch ke-2 error) → penunjuk tidak berubah, impor baru dibersihkan, data lama tetap tampil (tes Task 2).
3. PDF berikutnya membawa nilai baru (keterangan/JKN/provinsi tak dikenal, nomor urut bolong) → parser melempar dengan nomor baris, impor tidak menulis apa pun (tes Task 1).
4. Agent mengetik huruf kecil, spasi ganda, atau potongan NIK/porsi → tetap ketemu (tes Task 5).
5. Ganti provinsi setelah memilih kab/kota → kab/kota yang tak ada di provinsi baru direset, bukan menghasilkan 0 baris misterius (tes Task 5). Juga: belum ada impor sama sekali → API `rows: []`, halaman status kosong, bukan galat (tes Task 2).
